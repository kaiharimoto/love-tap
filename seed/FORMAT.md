# seed/FORMAT

The seeded year is spine events, authored as JSON Lines, one file per month, loaded only when the
app starts with `--seed=year`. The loader (`app/lib/spine/seed_loader.dart`) turns each line into a
spine event with a deterministic ULID, imports media into the blob store, and inserts read markers
and passive-state transitions from the people's rhythms (`seed/tools/finish.py` does the same
offline so the committed JSONL is complete and the loader never invents content).

## Files

```
seed/people.json            the two people, their hands, the world, the three anchors
seed/STYLE.md               how the year reads (arc, rhythms, voice, what to avoid)
seed/year/2025-09.jsonl     … one file per month … seed/year/2026-09.jsonl
seed/photos/index.<month>.json   photo id → scene description per month (merged by seed/tools/merge_index.py)
seed/photos/<id>.jpg        rendered photographs (1200×1600 or 1600×1200)
seed/videos/<id>.mp4        short rendered clips (poster is the first frame)
seed/voice/index.<month>.json    voice id → duration, speaker, setting (merged the same way)
seed/voice/<id>.ogg         synthesised voice-note audio (tools/sound/voice.py)
```

## A line

```json
{"key":"2026-08-21-0012","ts":"2026-08-21T22:14:08+01:00","author":"teo","type":"message","payload":{"text":"are you still in it"}}
```

| field | required | notes |
|---|---|---|
| `key` | yes | `YYYY-MM-DD-NNNN`, unique across the year; refs use `k:<key>` |
| `ts` | yes | ISO 8601 with offset; lines in a file must be in non-decreasing `ts` order |
| `author` | yes | `noor` or `teo` |
| `type` | yes | one of the seventeen ids in `docs/EVENT_TYPES.md` |
| `payload` | yes | per type, below; refs are written as `"k:<key>"` and resolved by the loader |
| `anchor` | no | one of the three anchor ids from `people.json`, on the event that carries it |

`id`, `seq`, `device`, `refs`, `blobs` are derived by the loader; never write them.

## Payloads (seed form)

| type | payload |
|---|---|
| `message` | `text`; optional `reply_to: "k:…"` |
| `photo` | `photo: "<id>"` (declared in `photos/index.<month>.json`); optional `caption`, `reply_to` |
| `video` | `video: "<id>"`, `duration_ms`; optional `caption` |
| `voice_note` | `voice: "<id>"`, `duration_ms` (the waveform is derived from the audio) |
| `reaction` | `target: "k:…"`, `feeling_id` |
| `message_edit` | `target: "k:…"`, `text` |
| `message_delete` | `target: "k:…"` |
| `feeling` | `feeling_id`, `intensity` 0–1 (two decimals), optional `hold_ms` |
| `state_declared` | `signal` (mood, status_line, availability, need, energy, place), `value` |
| `date_event` | `date_id`, `action` (planned/scheduled/done/rated/remembered), `title`; optional `when`, `place`, `rating` 1–5, `note` |
| `todo_event` | `todo_id`, `action` (added/assigned/done/reopened/removed), `text`; optional `assignee` |
| `milestone` | `milestone_id`, `kind` (anniversary/first/custom), `title`, `date`, `yearly` |
| `ritual_kept` | `ritual_id`, `title`, `kept_at`; optional `note` |
| `ping` | `schedule_id`, `text`, `fires_at`; optional `feeling_id`, `repeat` (daily/weekly/none) |
| `feeling_authored` | `feeling_id`, `name`, `family`, `colour`, `object_asset`, `haptic`, `sound`, `retired` |

`read_marker` and `state_passive` are generated by `seed/tools/finish.py`; do not author them.

Feeling ids come from `docs/FEELINGS.md` plus any `feeling_authored` earlier in the year
(`pigeon`, authored by Noor in October 2025; `soup`, authored by Teo in February 2026).

## Photo index entry

```json
{"id":"lift_buttons","by":"noor","scene":"the button panel of a hospital car-park lift, brushed steel, floor 3 lit, phone-flash reflection, slightly tilted","w":1200,"h":1600}
```

Scenes are rendered in Blender from that description by `blender/seed_photos/`; no photograph is
downloaded. Keep scenes to things that render as still lifes: objects, rooms, food, paper, water,
sky, hands are avoided.
